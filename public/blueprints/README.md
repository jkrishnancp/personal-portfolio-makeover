# Security Blueprint Library

This directory contains 250+ implementation blueprints representing real security programs delivered across enterprise, BFSI, retail, healthcare, manufacturing, and public sector engagements.

## File Naming Convention

Each blueprint filename is prefixed with a unique three-digit sequence number:

```
NNN-blueprint_topic_name.html
```

For example: `020-ioc_enrichment_workflow.html`, `024-ioc_enrichment_workflow.html`

### Same-topic blueprints are distinct projects

Multiple files may share the same base name (e.g., `ioc_enrichment_workflow.html`, `internal_audit_schedule.html`). This is intentional - these are **separate blueprints from different engagements**, not duplicates. Each numbered file represents a distinct project with its own scope, environment, and outcomes. The shared base name reflects that the same security domain was addressed across multiple clients or programmes over the years.

To verify any two files are distinct, compare their `<title>` tags or their content bodies - each project has unique context, tooling, and results.

## Maintenance Scripts

### `update_blueprints.py` - Batch theme processor

Transforms raw blueprint HTML files with the Corporate Executive Navy & Gold theme.

```bash
# From the repo root or blueprints parent directory:
python public/blueprints/update_blueprints.py \
  --input ./raw_blueprints \
  --output ./public/blueprints

# Options:
#   --input  / -i   Source directory containing raw HTML files (default: ./bllueprint)
#   --output / -o   Destination directory (default: ./blueprints)
#   --backup / -b   Create a timestamped backup of the input directory before processing
#   --dry-run / -n  Preview renames and changes without writing any files
```

What it does:
- Strips all inline `<style>` blocks from each file
- Injects a link to the shared `theme.css`
- Adds a consistent branded header with back-navigation links
- Adds a consistent footer with copyright
- Sanitizes filenames to web-safe format (replaces `&`, `→`, `+`, parentheses, etc.)
- Generates `file_mapping.json` mapping original names to sanitized names

Run this script whenever new raw blueprints are added to the source directory.

### `fix_links.py` - Navigation link patcher

Updates internal navigation links in already-processed blueprint files to use correct absolute URLs.

```bash
# Run from inside the blueprints directory:
cd public/blueprints
python fix_links.py
```

What it does:
- Replaces `href="../index.html"` with `href="/"` (portfolio home)
- Replaces `href="../security-blueprints.html"` with `href="/security-blueprints.html"` (blueprints index)

Run this script if blueprint files were processed before the URL scheme was finalised, or after any URL structure change.

### `file_mapping.json`

Auto-generated by `update_blueprints.py`. Maps the original (pre-sanitization) filenames to their current web-safe filenames. Used as a reference when troubleshooting broken links or tracing a blueprint back to its source.

### `theme.css`

Shared stylesheet applied to all blueprint HTML files. Provides the Corporate Executive Navy & Gold visual theme, including layout, typography (Inter + Playfair Display), and blueprint-specific component styles.

## Updating `blueprintsData.ts`

After adding new blueprints, update `src/data/blueprintsData.ts` to register them. Each entry needs:

```ts
{
  id: <next sequential number>,
  title: 'Human-readable title',
  category: 'Category (e.g. SIEM, Zero Trust, IAM)',
  role: 'Your role (e.g. Program Lead, Architect)',
  duration: 'Duration (e.g. 3 mo)',
  technologies: ['Tool A', 'Tool B'],
  problem: 'One-sentence description of the challenge.',
  result: 'One-sentence description of the outcome.',
  file: 'NNN-sanitized_filename.html',
}
```
